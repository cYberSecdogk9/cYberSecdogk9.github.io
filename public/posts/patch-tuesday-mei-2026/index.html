Patch Tuesday Mei 2026

Overzicht van alle CVE's uit de Microsoft Patch Tuesday van mei 2026, inclusief kritieke kwetsbaarheden in Azure, Windows en Office.
May 12, 2026 · 5 min · Wingineer

Inleiding#

Vandaag, 12 mei 2026, heeft Microsoft de maandelijkse Patch Tuesday uitgebracht. Deze maand worden er een groot aantal kwetsbaarheden gepatcht, verspreid over Windows, Azure, Microsoft Office en diverse andere producten. Hieronder vind je een volledig overzicht van alle CVE’s.

De updates zijn beschikbaar via Windows Update en het Microsoft Security Update Guide.

Aanbevelingen#

  • Installeer de updates zo snel mogelijk via Windows Update of WSUS/SCCM.

  • Bekijk de volledige details per CVE via het Microsoft Security Update Guide.
